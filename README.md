# Project Notes

## JSON Formatting
I have used **Quicktype** to generate and format the JSON objects due to the large size of the dataset. This ensures type safety and maintainability in the project.

## Placeholder Images
I have used **placeholder images** in the collection view cells since I do not have access to the original repository where the actual images are stored.

Additionally, the image retrieval is restricted, as seen in the attached error message:

## Fonts
Fonts will be **integrated into the production code** to ensure a consistent UI/UX.

## Architecture
The project follows the **MVVM (Model-View-ViewModel) architecture**, which helps in maintaining a clean separation between UI and business logic.

## Side Menu
The **SideViewController** was implemented **programmatically** instead of using Storyboard. This demonstrates my ability to work without Interface Builder when needed.

## Unit Tests
Unit tests are included to verify functionality. I considered implementing **UI tests**, including **UI snapshot testing**, but determined that it would be **overkill** for this project.

## Future Improvements
- Integration of real assets for images.
- Enhancing test coverage with UI tests if required.
- Performance optimizations in data parsing and rendering.
